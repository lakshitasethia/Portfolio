# Lakshita Sethia — portfolio

A paper-and-machine portfolio. The hero is a pencil portrait that draws itself and fills with
watercolour; a cursor lens reveals the same page underneath as chalk linework on dark ink.

Built with Vite, GSAP (ScrollTrigger, ScrollSmoother, SplitText, DrawSVG, Flip, Draggable,
Inertia, ScrambleText, MorphSVG) and three.js.

```bash
npm install
npm run dev
```

| File | What it does |
|---|---|
| `src/main.js` | Lens, intro, marquee, scroll sections, case studies, stamps |
| `src/portrait.js` | Self-drawing portrait and watercolour wash |
| `src/illo.js` | Generative hero garden and constellation |
| `src/bloom.js` | 3D peony (solid + wireframe under the lens) |
| `src/toolkit.js` | Stickers on strings that form figures; cut a string by hovering it |
| `src/footer.js` | Drafting-grid footer, render scene, isometric box, rolling links |
